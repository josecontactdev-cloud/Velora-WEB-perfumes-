# VELORA — demo e-commerce de perfumería

Versión single-screen: todo el sitio vive dentro de un único viewport, sin scroll vertical del documento.

## Comportamiento
- **Inicio:** la rueda del mouse cambia entre fragancias y nunca desplaza la página.
- **Catálogo / Nosotros / Contacto:** cambian como vistas dentro del mismo cuadro usando el menú.
- **Catálogo:** filtros + paginación sin salir de la pantalla.
- **Carrito:** persistente con `localStorage` y checkout demo por WhatsApp.
- **Producto:** modal con notas, descripción y precio.

## Ejecutar
Abre `index.html` o usa cualquier servidor estático (por ejemplo Live Server).
